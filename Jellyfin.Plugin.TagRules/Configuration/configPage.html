Tag rules

Each rule adds its "exclude tag" to any item that has none of its "marker tags", and removes the exclude tag again from any item that later gains a marker tag. Add one rule per grouping you want to filter by — for example, marker tags Kids and Family with exclude tag Not Kids Content lets you filter the Collections screen down to everything that isn't marked for kids. Changes take effect the next time the "Apply collection tag rules" scheduled task runs (Dashboard → Scheduled Tasks → Library), or immediately via that task's Run Now button.
